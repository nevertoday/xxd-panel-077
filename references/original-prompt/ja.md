# XXD Panel 077 オリジナルスタイル指示 · 日本語参考訳

アップロードした各写真を独立した上質なデザインポスターにし、複数写真を組み合わせず一枚ずつ出力します。全体は3:4縦位置で、上下二領域を厳密に同じ高さの1:1、各50%とします。

上部には元写真を残し、主体の同一性、構造、姿勢、実在感、自然な光と影、元の色彩の空気を保ちます。アート誌、独立出版物、展覧会画像の質感になる軽い上質な調整だけを行います。周囲の環境は自然に拡張できますが、主体を伸縮、歪曲、変更しません。

下部では、最も識別性の高い**主体、人物動作、輪郭構造、場面関係**をミニマルな紙彫刻コラージュへ再構成します。主体と物語の論理を保ち、写実的に描かず、概括した形、簡潔な層状面、明瞭な切り紙輪郭で再編し、一目で元が分かりながら上質で文芸的な転訳にします。

構図は通常のコラージュより精妙にし、**視覚重心、比率のリズム、余白配分、層の関係、正負形、図文秩序**を重視します。主体は適度に中央または少し偏心させ、前後の重なり、局部裁切、面の呼応、静かな余白で読解経路をつくります。背景と副次情報を削り、感情と場面関係を支える少数要素だけを残します。

素材は**紙彫刻コラージュと切り紙の層状質感**です。軽い紙目、切断面、前後レイヤー、柔らかな影、手作業の痕跡を残し、清潔、平面的、穏やかにします。過度なカートゥーン、滑らかなベクター、重いプラスチック3Dは避けます。

暗緑や空色中心の森系配色を避け、**人間的で癒やしのある柔らかなマカロン色**を使います。元写真で最も生命力と感情温度のある色を抽出して明度と純度を高め、クリーム白、オート麦色、霧ピンク、桃色、杏橙、レモンミルク黄、淡い湖水青、霧紫、柔らかな霞緑などの呼吸する浅彩関係へ再調整します。軽やかで親しみやすく、温かく新鮮で静かな、日光に照らされた色にします。汚れ、古び、暗さ、過冷却、蛍光、安価なキャンディ色を避けます。

文字は**簡潔な英語雑誌レイアウト**とし、**小さく抑制された、機械誤差のあるタイプライター書体**と少量の情報を使えます。簡潔な大見出し一つとごく少量の補助文字は許されますが、文字の視覚重量を低くし、主体を圧倒しません。旅行誌や独立美術誌のように主体、余白、紙面と自然に構成し、テンプレート見出し欄にしません。

全体は**上質、文芸的、余白豊か、癒やし、人間的な旅行雑誌ポスター**にします。建築、人物、動物、植物、器物、乗り物、自然景観のどれでも、下部は明確な同一性、簡潔な物語、精緻な編集設計を保ちます。過度なカートゥーン、複雑な細部、安価なコラージュ、テンプレート構図、強いCG感を避けます。
